# RankLoop

## Requirements

- Node.js >= 20

## Getting started

```bash
npm install
npm run build
npm start
```

## Scripts

| Script | Description |
| --- | --- |
| `npm run build` | Compile TypeScript to `dist/` |
| `npm run dev` | Compile in watch mode |
| `npm run typecheck` | Type-check without emitting |
| `npm run clean` | Remove `dist/` |
| `npm start` | Run the compiled output |
