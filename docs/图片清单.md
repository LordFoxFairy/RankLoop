# 图片清单

把图片按下表文件名放进 `docs/images/`，我会复制到静态资源目录
（`apps/api/public/img/`）并接入对应页面。

命名必须完全一致，否则我找不到。

---

## 必需（缺了会影响 SEO 或展示）

### 1. `og-cover.png`

| 项 | 要求 |
| --- | --- |
| 尺寸 | **1200 × 630**（社交分享标准比例，不要改） |
| 格式 | PNG 或 JPG |
| 用途 | 首页与所有页面的 `og:image`。分享到微信 / X / Slack 时显示的大图 |
| 内容建议 | 深色背景 + RankLoop 标识 + 一句话主张（如「不合格的内容，发不出去」） |
| 注意 | 文字要大，缩略图下仍需可读；四周留 60px 安全边距 |

**这张最重要** —— 缺了社交分享只有一行文字链接，点击率差很多。

### 2. `logo.svg`

| 项 | 要求 |
| --- | --- |
| 格式 | SVG（矢量，任意缩放不糊） |
| 尺寸 | 正方形画布，建议 `viewBox="0 0 32 32"` |
| 用途 | 顶部导航栏、favicon |
| 注意 | 单色或双色，深浅背景下都要能看清 |

目前用的是我写的临时 SVG（蓝底白色 R 变形），可以替换。

## 提供后我会做什么

1. 复制到 `apps/api/public/img/`
2. 接入首页对应位置
3. 给每张图加 `alt`（SEO 规则会检查，缺 alt 会扣分）
4. 图片过大时压缩（体积影响加载速度，进而影响排名）
5. 用浏览器实测确认加载正常、深浅色模式都可读

## 格式建议

- **优先 PNG**：截图与含文字的图，避免 JPG 压缩糊字
- **图标用 SVG**：矢量，体积小且清晰
- **单张控制在 300KB 内**：超过会拖慢首屏
- **不要用 WebP 作为唯一格式**：兼容性稍差，除非同时提供 PNG 兜底
