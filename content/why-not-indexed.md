# 内容发布了但 Google 不收录，怎么排查

页面上线好几天，搜索 `site:你的域名` 却查不到——这是最常见也最让人焦虑的情况。
原因可能是技术缺陷，也可能只是时间没到。这两类必须分开处理：
前者立刻能修，后者做什么都没用。

按下面的顺序排查，从最致命的开始。

## 第一层：搜索引擎能不能访问到这个页面

### robots.txt 是否拦住了

访问 `你的域名/robots.txt`，看是否有 `Disallow` 规则误伤了目标路径。

```
User-agent: *
Disallow: /blog/     ← 整个 blog 目录都不会被抓取
```

上线前用测试环境的 robots 是常见事故：测试环境通常全站 `Disallow: /`，
一旦连同配置发到生产，整站消失。

### 页面是否带了 noindex

查看页面源码里的：

```html
<meta name="robots" content="noindex">
```

这一行的意思是「明确告诉搜索引擎不要收录」。CMS 的草稿模式、
预发布环境的模板经常留下它，发布后忘记去掉。

同样要检查 HTTP 响应头里的 `X-Robots-Tag: noindex`，
这个在源码里看不到，容易漏。

### 页面返回的状态码是不是 200

用命令确认，而不是靠浏览器看起来正常：

```bash
curl -I https://你的域名/页面路径
```

软 404（返回 200 但内容是「页面不存在」）尤其危险——
浏览器看着没问题，搜索引擎却会判定为低质量页面。

## 第二层：搜索引擎知不知道这个页面存在

### sitemap 里有没有它

`sitemap.xml` 是告诉搜索引擎「我有哪些页面」的主要途径。
检查两件事：URL 在不在里面，以及**这些 URL 是否真的可访问**。

sitemap 里放死链比没有 sitemap 更糟——它会降低搜索引擎对整份
sitemap 的信任度。逐条验证：

```bash
curl -s https://你的域名/sitemap.xml \
  | grep -oE '<loc>[^<]*</loc>' \
  | sed 's/<[^>]*>//g' \
  | while read u; do echo "$(curl -s -o /dev/null -w '%{http_code}' "$u") $u"; done
```

### 有没有主动提交

- **Google**：在 Search Console 提交 sitemap。Google 不支持 IndexNow 协议。
- **Bing / Yandex / Seznam / Naver**：支持 [IndexNow](https://www.indexnow.org/)，
  发布后可以主动推送，通常几分钟内就有反应。

提交只是「告知」，不等于「立刻收录」。

### 有没有内部链接指向它

完全没有任何链接指向的孤岛页面，即使在 sitemap 里也容易被忽略。
从相关页面加几个内链，是成本最低的改善。

## 第三层：页面本身值不值得收录

### canonical 指向哪里

```html
<link rel="canonical" href="https://别的域名/其他页面">
```

canonical 指向别处，等于告诉搜索引擎「请收录那一页，不要收录我」。
跨域名的 canonical 会把权重整个转让出去，是静默且严重的错误。

### 内容是否单薄

只有几十个字、或者与站内其他页面高度重复的内容，
搜索引擎可能抓取了但选择不放进索引。Search Console 会显示为
「已抓取——尚未编入索引」。

这种情况下补充实质内容比反复提交有用得多。

## 第四层：只能等的部分

排除上面所有技术问题后，剩下的因素做什么都无法加速：

**站点年龄。** 新域名通常需要数周到数月才会获得正常的收录速度与排名，
业内称为观察期。这期间即使技术完美，收录也会明显偏慢。

**外部链接。** 其他网站引用你，是搜索引擎判断内容价值的重要信号。
零外链的新站，权重接近于零。

**抓取预算。** 搜索引擎分配给每个站点的抓取频次有限，
新站或低权重站点的配额很低。

Google 官方文档明确说明：
> Google 不保证会抓取、索引或提供你的页面，即使它符合 Google 搜索要素。

也就是说，**不存在任何工具或付费方式可以强制收录**。
声称能保证收录或排名的服务不可信。

## 排查清单

按顺序检查，每一项都有明确的判定方法：

1. robots.txt 没有拦截该路径
2. 页面无 `noindex`（含 HTTP 响应头）
3. 状态码为 200，且不是软 404
4. URL 在 sitemap 中，且 sitemap 内全部 URL 可访问
5. 已在 Search Console 提交 sitemap
6. 至少有一个内部链接指向该页
7. canonical 指向页面自身
8. 内容有实质信息量，非重复

前八项都通过之后仍未收录，那就是第四层的问题——耐心等待，
同时持续产出内容、积累外部引用。
